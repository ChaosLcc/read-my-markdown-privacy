# Read My Markdown Privacy Policy

Read My Markdown 浏览器扩展的中英文隐私政策静态站点。

- 发布者：WSD_超哥哥
- 支持邮箱：420021818@qq.com
- GitHub Pages 地址：https://chaoslcc.github.io/read-my-markdown-privacy/

## 文件

- `index.html`：中文和英文隐私政策，无远程脚本、字体或分析服务。
- `icons/`：站点图标和产品标识。
- `.nojekyll`：直接发布静态文件，无需 Jekyll 处理。

## 发布

GitHub Pages 使用 `main` 分支的根目录（`/`）作为发布来源。
更新政策后提交并推送到 `main`，等待 Pages 部署完成。

Edge Add-ons 的 **Privacy policy URL** 应填写上面的 Pages 地址。
提交商店审核前，请确认该地址无需登录即可打开，且政策内容与扩展的实际行为一致。
